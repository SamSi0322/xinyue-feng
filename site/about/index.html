In short

The Java platformer I designed, drew and coded on my own grew out of a game I loved, Ace Attorney. Class assignments became projects too: a recipe app that turns what’s in your fridge into three recipes with photos, and a tic-tac-toe game with a rule-based AI opponent. In summer 2026 I built a Harry Potter mod for Terraria and took it through route-by-route testing to a 1.0 release candidate.

Much of my work has been in teams: a 48-hour game jam, two co-authored research papers, and internships in computer vision, game technology and sports-event operations.

How they were made

The original projects are my own: the Java game (2024), the recipe app (February 2026), the tic-tac-toe game with its rule-based AI (April 2026) and Wizarding World (2026). I developed Wizarding World with AI tools, writing the code with Claude Code and generating the sprites with AI image generation, then tested it route by route and took it to a 1.0 release candidate.

The 2026 portfolio editions (the browser port of the Java game, the tic-tac-toe minimax opponent and “Show AI thinking” overlay, the recipe app’s redesign and demo) and this website were built with AI coding tools. Each project page says what changed, and the original Java and tic-tac-toe files are kept in the source repository.
