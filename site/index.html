02 · Java game · 2024

The Adventures of Edgeworth

An Ace Attorney platformer

My 2024 Java course project: a six-level platformer starring Miles Edgeworth, written from scratch in Swing, with sprites I drew in Aseprite and levels I laid out cell by cell in Excel. A 2026 web port lets you play it in the browser.

  • Java
  • Swing
  • Multithreading
  • Aseprite
  • HTML canvas port

03 · Full-stack web · 2026

AI Recipe Remix

From leftovers to plated recipes

My February 2026 class project: tell it what’s in your kitchen, your diet and how much time you have, and it suggests three recipes and generates a photo of each dish. A React and Tailwind front end talks to an Express server that keeps the OpenAI key private.

  • React
  • Tailwind CSS
  • Express
  • OpenAI API
  • Vite

04 · Game AI · 2026

Tic-Tac-Toe vs. AI

Three opponents, one unbeatable

A browser game that shows how the computer thinks. Easy plays loosely, Medium is my rule-based AI from the original class assignment, and Hard is a minimax search that cannot lose. Switch on “Show AI thinking” to see its score for every square.

  • JavaScript
  • Minimax
  • Alpha-beta pruning
  • Accessibility

About

“Player one”

I’m Xinyue Feng, also known as Lily. I study Computer Science at Kean University, and I’m most interested in human–computer interaction: the point where software meets the person using it.

My Java platformer grew out of two things I loved: the little adventure games on 4399 that I played as a kid, and Capcom’s Ace Attorney. Outside class I’ve interned in computer-vision data processing and at a game technology company, and helped ship a prototype in a 48-hour game jam.
