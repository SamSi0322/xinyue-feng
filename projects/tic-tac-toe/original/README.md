# Play with AI - Tic-Tac-Toe

This project is a JavaScript-based browser game created for Unit 10 AS1: Class activity: Play with AI.

## Description
The player plays as X and competes against an AI opponent that plays as O.  
The AI analyzes the game board and chooses moves automatically.

## Features
- Player vs AI
- Win / lose / draw detection
- Restart round button
- Scoreboard
- Responsive design
- Public deployment ready
